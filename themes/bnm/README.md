# bnm

Hugo theme for bnmoch3.org, derived from [tomfran/typo](https://github.com/tomfran/typo) (MIT, see
`LICENSE`). Light only, plain CSS and JS, no build step; the standard Hugo edition (0.148.x) builds it.

Design lives in `assets/css/tokens.css` and `[params.fonts]` in the site's `hugo.toml`.
See `docs/DEVELOPMENT.md` in the site repo.
